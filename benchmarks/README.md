# CUDA Drone Vision Benchmarks

This directory will contain benchmark programs and measured results
for the CUDA image-processing pipeline.

## Benchmark plan

- Compare CPU and CUDA implementations on identical input data.
- Verify output correctness before comparing performance.
- Measure CUDA kernel execution time using CUDA events.
- Measure end-to-end time separately, including memory transfers.
- Test multiple image resolutions.
- Record GPU model, CUDA version, input dimensions, and repeat count.
